🌟 Vision
AirGuard transforme le "sabotage silencieux" des fuites d'air comprimé en une donnée visible et exploitable. En combinant un biomarqueur fluorescent organique et un Digital Twin intelligent, nous permettons aux industries de réduire leurs pertes énergétiques jusqu'à 30%.

🚀 Fonctionnalités ClésAura-Scent Visualization : Localisation précise via Computer Vision et traceur fluorescent (visible sous UV).
Digital Twin 3D : Simulation temps réel de l'infrastructure sous A-Frame.Détection Multi-sensorielle : Fusion de données (pression, vibration, ultrasons) pour une fiabilité maximale.
IA Prédictive : Algorithme estimant le coût financier ($) et l'impact carbone ($CO\_2$) de chaque fuite.
Architecture Edge : Capacité d'upload du code de détection directement sur les caméras de surveillance existantes.

🍃 Impact Écologique & ROI
Notre étude démontre qu'une fuite de 1mm non détectée coûte environ 950€/an.

Coût AirGuard : < 50€ d'équipement (infrastructure existante exploitée).

ROI : Inférieur à 2 mois.

Bilan Carbone : Réduction immédiate de l'empreinte électrique du compresseur.

💡 Note sur le Biomarqueur
Le traceur utilisé est la Fluorescéine Sodique, une matière organique biodégradable, non toxique et compatible avec les environnements industriels agroalimentaires.
